# MediBridge
A healthcare access platform designed to help people discover healthcare facilities and connect with providers 
To make healthcare access easier and more accessible, particularly for underserved communities in Nigeria and eventually across Africa.
Healthcare facility discovery
Healthcare provider information
Appointment requests
Simple and accessible user experience
Currently in the planning and early development stage.
MediBridge is also my practical learning project as I develop skills in mobile application development, backend engineering, cloud computing and platform engineering.

More updates coming as development progresses.
